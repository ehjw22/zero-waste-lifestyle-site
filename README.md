# Zero-Waste Lifestyle Website

My first front-end web development project, built in Year 1 of my Diploma in IT at Singapore Polytechnic (Front-End Development, CA1). It's a three-page static website about living a zero-waste lifestyle.

> This is an early project, kept here to show where I started. See my [pinned repositories](https://github.com/ehjw22) for more recent work.

## Pages

| Page | What it covers |
|------|----------------|
| **Home** (`html/index.html`) | The five zero-waste principles (refuse, reduce, reuse, recycle, rot), waste statistics with conclusions, and real-world examples from around the world |
| **About Me** (`html/aboutMe.html`) | My interest in eco-friendly living, my experiences with waste reduction, and my favourite green hacks |
| **Aspirations** (`html/aspirations.html`) | My zero-waste goals, the challenges I expect with each, and how I plan to overcome them |

## Built with

- HTML5
- CSS3, with separate stylesheets for the layout, navigation bar and footer
- No frameworks or libraries

## Running it

Open `index.html` in any browser. It redirects to the home page in the `html/` folder. No build step is needed.

## What I learned

- Structuring a multi-page site with shared navigation and a shared footer
- Using CSS layouts to arrange text, images and statistics
- Organising HTML, CSS and images into a clean folder structure
